# Python Learning

记录我的 Python 学习过程，通过练习逐步建立编程、数据处理和项目开发能力。

## Day 1

### 学习内容

- Python 变量、输入和输出
- `if / elif / else` 条件分支
- 列表 `list`
- `for` 循环
- 字符串的 `split()` 方法
- 列表的 `append()` 方法
- 类型转换：`int()`、`float()`
- f-string 格式化输出

### 完成的程序

- `main.py`：基础变量与输出练习
- `discount.py`：商品折扣计算器
- `score_list.py`：成绩统计分析程序

### 成绩分析程序功能

- 读取一行中的多个成绩
- 计算总分和平均分
- 统计最高分和最低分
- 统计各成绩等级人数

## Day 2

### 学习内容

* `for` 和 `while` 循环的区别
* 使用 `break` 结束整个循环
* 使用 `continue` 跳过本轮循环
* 使用 `range()` 控制循环范围和步长
* 使用 `range()` 正序、倒序遍历列表
* 使用 `enumerate()` 同时获取序号和元素
* 使用 `try-except ValueError` 处理非法输入
* 使用 `if not scores` 判断空列表
* 输入数据的类型检查和范围检查
* 手动计算总分、平均分、最高分和最低分

### 完成的程序

* `day02_loop.py`：成绩列表统计练习
* `day02_while.py`：循环录入成绩和输入验证
* `day02_score_manager.py`：完整成绩录入与统计程序
* `day02_range.py`：`range()`、倒序遍历和 `enumerate()` 练习

### 成绩管理程序功能

* 连续录入多个成绩
* 输入 `q` 结束录入
* 拒绝非整数输入
* 拒绝不在 0～100 范围内的成绩
* 处理没有录入成绩的情况
* 计算平均分、最高分和最低分
* 统计及格人数
